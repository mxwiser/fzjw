# fzjw

正方教务系统成绩分项下载脚本，用于尝试导出包含平时分等成绩分项的成绩单。

> [!WARNING]
> **本项目已停止维护。**
>
> 该导出接口目前已被许多院校关闭或限制权限。即使教务系统页面仍显示相关功能，也可能只返回“无功能权限”或无有效数据的表格。本项目不能绕过学校的权限控制，也不保证在任何院校可用。
>
> 相关反馈：[Issue #1：无功能权限](https://github.com/mxwiser/fzjw/issues/1)、[Issue #3：该 API 已经被大多数院校关闭](https://github.com/mxwiser/fzjw/issues/3)。

## 项目状态

- 当前状态：停止维护，仅保留作技术参考。
- 适用范围：仍然开放成绩分项导出接口、且当前账号具有相应权限的正方教务系统。
- 不适用情况：接口被关闭、学校限制导出权限，或教务系统已经更换接口。
- 本项目不会提供绕过认证、越权访问或规避学校限制的方法。

如果脚本提示请求成功，但下载的文件很小或内容显示“无功能权限”，通常是服务器端权限限制，并非浏览器下载故障。

## 使用方式

仓库中的 `example.js` 是一个用户脚本示例。使用前需要根据自己学校的教务系统域名调整脚本头部的 `@match` 规则。

请只在自己的账号和学校允许的范围内使用。登录 Cookie 属于敏感凭据，不要发送给他人，也不要提交到公开仓库。

## 原理

脚本调用正方教务系统的成绩分项导出接口，尝试获取包含课程成绩和平时分等分项的 Excel 文件。

### 历史接口地址

```text
教务系统前缀 + /cjcx/cjcx_dcXsKccjList.html
```

例如：

```text
https://example.edu.cn/jwglxt/cjcx/cjcx_dcXsKccjList.html
```

不同学校的部署路径和接口权限可能不同。

### 请求方式

`POST`，请求体类型为：

```text
application/x-www-form-urlencoded
```

请求需要在用户已正常登录教务系统的会话中发出，由浏览器自动携带当前站点的 Cookie。

### 历史请求参数

```js
[
    ["gnmkdmKey", "N305005"],
    ["xnm", xnm], // 学年号，可在查分页面的网络请求中查看
    ["xqm", xqm], // 学期号
    ["dcclbh", "JW_N305005_GLY"],
    ...[
        "kcmc@课程名称",
        "xnmmc@学年",
        "xqmmc@学期",
        "kkbmmc@开课学院",
        "kch@课程代码",
        "jxbmc@教学班",
        "xf@学分",
        "xmcj@成绩",
        "xmblmc@成绩分项"
    ].map((column) => ["exportModel.selectCol", column]),
    ["exportModel.exportWjgs", "xls"],
    ["fileName", "成绩单"]
]
```

在接口仍可用且账号具备权限时，服务器会返回成绩单文件；否则可能返回错误页面、空文件或包含权限提示的文件。

## 常见问题

### 下载的文件只有几 KB，并显示“无功能权限”

这是学校服务器返回的权限提示。脚本无法在客户端解决，需要以学校实际开放的功能为准。

### 按钮没有出现

请检查：

1. `@match` 是否包含当前教务系统域名；
2. 当前页面是否存在 `xnm`、`xqm` 和 `search_go` 元素；
3. 教务系统是否已经更新页面结构。

### 是否还会适配新的教务系统接口？

目前没有维护和适配计划。欢迎 Fork 本项目自行研究，但请遵守学校规定并保护个人账号信息。
